GlazeSMP – Info & Tutorials

Everything you need to know about the server and bot.

Getting Started

Welcome to GlazeSMP! This server offers a unique Minecraft experience with custom features, tickets, and moderation tools.

  • Use /help in Discord to see all available commands.
  • Use /ticket to create a support ticket.
  • Staff can use /webapp to get a login code for the full dashboard.

Discord Commands

  • /webapp – Get a login code for the dashboard (staff only)
  • /ticket – Create a support ticket
  • /report – Report a bug
  • /ping – Check bot latency
  • /help – Show all commands

Tutorials

How to get support:

  1. Use /ticket in any Discord channel.
  2. A private channel will be created for you.
  3. Explain your issue and wait for a staff member.

How staff can access the dashboard:

  1. Use /webapp in Discord to receive a login code.
  2. Click the login button on the landing page.
  3. Enter the 6-digit code to access the full dashboard.

About GlazeSMP

GlazeSMP is a Minecraft server focused on community, building, and fun. The bot helps manage tickets, moderate chat, and provides useful utilities for both players and staff.
